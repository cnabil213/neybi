Test : enregistrement sur le disque N:

Ce test vérifie, sur ce PC, que l'Outil Formulation pourra enregistrer le rapport de shift sur le disque partagé. Il ne modifie rien d'autre.

Test en cours…

Comment faire le test (5 minutes)

  1. Copiez ce fichier dans le dossier de l'outil, par exemple N:\MFG\Formulation\Outil formulation.
  2. Double-cliquez dessus pour l'ouvrir dans Microsoft Edge.
  3. Cliquez sur « Tester l'enregistrement », choisissez ce même dossier, puis acceptez les autorisations d'Edge. Si Edge propose « Autoriser à chaque visite », choisissez-le.
  4. Fermez complètement Edge (toutes les fenêtres), puis rouvrez ce fichier.
  5. Cliquez sur « Copier le résultat » et envoyez-le à Claude.

Si vous vous connectez chacun avec votre propre compte Windows, refaites le test avec le compte d'un collègue.
